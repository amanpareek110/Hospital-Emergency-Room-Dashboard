# 🏥 Hospital Emergency Room Dashboard – Excel

An interactive **Hospital Emergency Room Analytics Dashboard** built in Microsoft Excel to analyze patient flow, waiting time, and patient satisfaction.

## 📊 Dashboard Overview

This dashboard provides a clear and interactive view of Emergency Room performance through key KPIs and visualizations.

### Key Metrics

* 👥 **Total Number of Patients**
* ⏱️ **Average Patient Waiting Time**
* 😊 **Patient Satisfaction Score**
* 📅 **Daily Patient Trends**

### 📈 Visual Analysis

The dashboard includes:

* Daily trend of Emergency Room patient visits
* Average waiting time analysis
* Patient satisfaction score trends
* KPI cards for quick performance monitoring
* Interactive charts for easier data interpretation

## 🛠️ Tools & Skills Used

* **Microsoft Excel**
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Analysis
* Dashboard Design
* Data Visualization

## 🎯 Objective

The main objective of this project is to transform hospital emergency room data into an easy-to-understand visual dashboard that helps identify patient volume trends, monitor waiting times, and evaluate overall patient satisfaction.
